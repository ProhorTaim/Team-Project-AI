## Что это?

**Team Project AI** - это веб-приложение, созданное для студентов, ищущих идеи и предложения для реализации проектов. Приложение позволяет студентам сформулировать или развить идею для проекта, проверить уникальность своей идеи, а также изучить уже реализованные проекты на схожие темы. 

## Быстрый старт

1. Перейдите на [team-project-ai.vercel.app](https://team-project-ai.vercel.app)

2. Введите описание вашей идеи проекта в поле ввода

3. Нажмите кнопку "Развить идею" или нажмите Enter

4. Получите подробный анализ:
   - Оценку релевантности с похожими проектами из архива
   - Рекомендации по развитию идеи
   - Предложения по реализации, стеку и структуре

## Возможности

- **Анализ идей**: ИИ анализирует вашу идею и помогает её развить
- **Поиск похожих проектов**: находит релевантные проекты из архива
- **Двухшаговый анализ**: сначала фильтрация, затем подробное исследование
