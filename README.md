## Что это?

**Team Project AI** — веб-приложение, созданное для студентов, ищущих вдохновение и идеи для курсовых и выпускных проектов.

Проблема, которую решает проект:
- Студенты часто не могут сформулировать или развить идею для проекта
- Нет удобного инструмента для проверки уникальности идеи
- Сложно найти похожие реализованные проекты для изучения опыта

Приложение основано на системе **"Team Project"** УрФУ — базе данных проектов, которая помогает студентам развивать свои идеи с помощью ИИ, находить похожие проекты и получать рекомендации по улучшению.

---

## Быстрый старт

1. Перейдите на [team-project-ai.vercel.app](https://team-project-ai.vercel.app)

2. Введите описание вашей идеи проекта в поле ввода

3. Нажмите кнопку **"Анализировать"** или нажмите Enter

4. Получите подробный анализ:
   - Оценку релевантности с похожими проектами из архива
   - Рекомендации по развитию идеи
   - Предложения по функционалу и технологиям

---

## Возможности

- **Анализ идей** — ИИ анализирует вашу идею и помогает её развить
- **Поиск похожих проектов** — находит релевантные проекты из архива УрФУ
- **Двухшаговый анализ** — сначала фильтрация, затем подробное исследование
- **Архив проектов** — доступ к базе данных реализованных проектов
- **Markdown форматирование** — красивое отображение результатов
- **Анимации** — плавное появление результатов анализа
- **Адаптивный дизайн** — удобно на любых устройствах
